## 🎨 Customization Tips

### Change Primary Color
```css
/* In style.css */
:root {
    --primary: #YOUR_COLOR;
    --accent: #LIGHTER_SHADE;
}
```

### Adjust Hero Height
```css
.hero-premium {
    min-height: 900px; /* Change from 800px */
}
```

### Modify Animation Speed
```css
.feature-card {
    transition: all 0.5s ease; /* Change from 0.3s */
}
```

### Change Grid Columns
```css
.features-grid {
    grid-template-columns: repeat(2, 1fr); /* 2 columns */
}
```
