🔐 Secure Authentication System

PHP & MySQL User Registration and Login System

✨ Security Features

  • Password Hashing - Using PHP password_hash() with bcrypt
  • Secure Login - password_verify() for authentication
  • SQL Injection Protection - Prepared statements
  • Session Security - HTTPOnly cookies & regeneration
  • Session Timeout - 30 minutes inactivity
  • Email Validation - Filter_var validation
  • Password Strength - Letters & numbers required
  • XSS Protection - htmlspecialchars() output
